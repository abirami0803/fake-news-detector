Fake News Detector 📰

Machine Learning project to detect Fake and Real news using Python.

Accuracy: ~99% using PassiveAggressiveClassifier

Files
- app.py - Main code
- Dataset - https://www.kaggle.com/datasets/clmentbisaillon/fake-and-real-news-dataset (File >25MB so link given)

How to Run
pip install pandas scikit-learn
python app.py
